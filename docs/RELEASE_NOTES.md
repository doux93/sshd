# sshx 0.2.0 体验版

- Windows 默认打开本地工作台，新增版本信息、首次连接步骤与“保存并连接”。
- 浅色/深色主题、较亮的深色界面、统一中文字体和紧凑工具栏。
- 双终端分屏、独立聚焦，常用命令收藏、编辑和复制。
- 上传队列显示进度和服务器保存阶段，支持取消、失败重试；切换会话或关闭文件面板后仍继续。
- 连接错误给出可操作的排查建议，手机通知显示权限与环境指引。

下载适合系统的 ZIP，解压后阅读 QUICKSTART.md。Linux/Windows amd64 构建通过自动化验收后发布，旁附 SHA-256 校验文件。

已知边界：手机只读；真实设备 Web Push、macOS 尚待实机验收；服务重启不能恢复原 SSH 终端；上传队列不跨页面刷新恢复；下载由浏览器管理。构建链上游低危依赖详情见 VALIDATION.md。

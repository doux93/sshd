# 修订说明 — 2026-11-16

## 文件与凭据安全

- 修复删除、递归删除、重命名符号链接误操作目标文件的问题；增加真实 OpenSSH SFTP 回归测试。
- 上传及工具文件写入采用临时文件和重命名提交，中断不破坏已有文件，保留原文件权限。
- 禁止对根目录、`.`、`..` 等路径直接执行删除或重命名。
- 修复过期登录凭据被续期复活、HTTP 退出只清 Cookie 不撤销凭据的问题。
- 退出登录立即断开相应 WebSocket，并定期检查现有连接的认证有效性。
- 加入浏览器来源检查、JSON 请求体上限、登录速率及 Argon2 并发上限。
- 凭据加密密钥读写加锁；解密绑定请求 ID，并拒绝无效 nonce。
- 节点保存时凭据失败会补偿回滚，避免出现半更新的节点和密码。
- 审计记录不再明文持久化工具参数中的文件内容或命令秘密。旧审计记录不会自动改写。

## AI 与前端

- 任意 Shell 命令仅允许 trusted 节点执行；readonly/confirm 使用固定 `inspect_system` 和其他只读工具。
- confirm 返回需要人工处理的错误，不宣称已有自动审批队列。
- Ctrl+K 结果显示为预览并可复制，不直接写入 PTY；拒绝控制字符及多行结果。
- 读取近期终端输出不再创建临时附着，也不再延长空闲会话生命周期；备用屏幕模式下拒绝 AI 读屏。
- MCP 工具 schema 明确包含 nodeId；限制命令输出、执行时长、文件读取与提示上下文大小。
- 页面先从认证接口获取运行模式，移除无效的内联脚本注入；支持静态入口和 PWA 缓存入口。
- 修复监控 WebSocket 数据重复 JSON 解析异常。
- 修复连接编辑框监控开关、采集间隔及 AI 策略没有保存的问题；编辑保留已有告警规则。
- 登录失败显示网络错误，登录后的跳转限制为同源路径。

## 生命周期与工程质量

- SSH、SOCKS 握手落实超时与取消；keepalive 增加响应期限。
- 命令超时关闭通道，不无限等待远端处理 SIGKILL；关闭 ssh-agent 连接及其他资源。
- WebSocket 发送改为有界队列，慢客户端不能阻塞全局事件和监控。
- 修复复用通道 ID 时旧 goroutine 关闭新附着的问题；慢订阅者触发重新附着，不误报整个会话结束。
- 重连先重置终端再回放，避免正常输出重复追加；断开会取消待执行的重连定时器。
- 监控停止会关闭读取流，结束的采集器不再上报为运行中，重复旧样本不参与持续告警判断。
- 会话先注册再启动读泵，关闭幂等化，终端写入与后端 resize 序列化。
- 多会话节点选择仍存活的会话，已结束会话保留节点关联以便重连。
- SQLite 迁移原子提交；远程模式默认 Secure Cookie；支持 SIGTERM；修正文档及 systemd 首次密码文件权限。

## 兼容性

原有数据库结构及加密格式兼容，没有重置用户数据。原先 readonly 下通过白名单执行 Shell 的行为已收紧；需要自动查询时改用 inspect_system，需要任意命令时显式设为 trusted。

Ctrl+K 改为预览和复制；远程 HTTP 测试需指定 `--secure-cookies=false`。这些变化是为了让实际行为符合安全边界。

## 验证与剩余边界

验证记录见 `VALIDATION.md`。本版本不承诺终端跨服务进程重启恢复、完整 VT 屏幕恢复或完整 MCP Streamable HTTP 兼容。macOS 钥匙串、真实移动推送和长期运行压测需要在实际部署环境验证；Windows Credential Manager 已通过原生测试。
